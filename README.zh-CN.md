# AlonaBot OneBot 11 适配器

[English](README.md)

<p align="center">
  <img src="assets/onebot.png" alt="OneBot" width="160">
</p>

通过正向或反向 Universal WebSocket 接入 OneBot 11 实现端，支持媒体及递归转发节点。

## 快速使用

使用 Core v0.3.0 或更高版本，在运行 Core 的机器上执行：

```fish
alonabot install --source AlonaBot/alonabot-adapter-onebot11 --yes
```

添加 OneBot11 账号并配置正向或反向连接。
